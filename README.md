# Contact Manager Pro

A desktop contact management application built with Java Swing.

## Features

- Add contacts
- Search contacts
- Delete selected contacts
- Sort contacts alphabetically
- Save contacts automatically
- Load contacts automatically on startup
- Contact counter
- Status bar updates
- JTable contact display

## Technologies Used

- Java
- Java Swing
- ArrayList
- File I/O
- JTable
- Object-Oriented Programming (OOP)

## Concepts Demonstrated

### Data Structures

- ArrayList<Contact>

### Algorithms

- Linear Search
- Sorting using Comparator

### Programming Concepts

- Classes and Objects
- Event Handling
- GUI Development
- File Persistence
